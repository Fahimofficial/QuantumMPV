## What mpvRx covers

- Local video and music libraries
- Network shares and direct URLs
- Jellyfin and Navidrome/Subsonic servers
- Torrent, HLS, MP4, and supported online sources
- HDR pipelines, shaders, Anime4K, ambient effects, and filters
- Dual subtitles, online search, styling, and speech-to-subtitle tools
- Google Cast, picture-in-picture, background playback, and playlists
- `mpv.conf`, `input.conf`, Lua, JavaScript, and custom player buttons

:::note
Device codecs, GPU drivers, server features, and remote media formats vary. The docs identify where behavior depends on the device or external service.
:::
